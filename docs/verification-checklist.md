# 发布前真机验证清单

本项目无自动化测试（UI 与系统服务强耦合）。每次发 release 前按本清单过一遍，
结果记入 release notes 或对应 issue。`✓` 视设备能力标注 N/A。

## 环境记录

- 机型 / ROM / Android 版本：
- Root：有（Magisk 版本）/ 无
- 安装方式：覆盖升级 / 卸载重装

## 核心链路

- [ ] 控制中心磁贴点击 → 热点开启，磁贴立即变激活（乐观刷新），完成后状态正确
- [ ] 再次点击 → 热点关闭，状态回滚正确
- [ ] 面板展开期间在系统页手动开关 → 磁贴回到面板时状态同步
- [ ] 磁贴长按 → 按配置打开本 App 设置页
- [ ] 桌面图标点击 → 按 `launcherClick` 配置行为执行
- [ ] 桌面图标长按 → shortcut 菜单正常

## 凭据与模式

- [ ] 默认模式（进阶未勾、凭据未填）：能读出系统热点名/密码并成功开启（Root 机）
- [ ] 诊断页显示「系统热点名称 / 系统热点密码：N位（*…）」
- [ ] 进阶模式：自定义名称密码生效，热点以自定义凭据开启
- [ ] 无 Root 且反射不可用机型：失败时报错并引导进设置页/系统页，不伪造凭据

## 边界

- [ ] 快速双击磁贴 → 只执行一次，提示「操作进行中」
- [ ] 开启失败 → 磁贴回到未激活（乐观状态被纠正）
- [ ] Magisk 首次授权弹窗 → 超时后设置页「重测 Root」可恢复检测

## 兼容性抽样（有设备条件时）

- [ ] Android 16+ 设备（反射被拦场景）
- [ ] API 26 设备（isLocked 守卫路径）
- [ ] 无 Root 设备（反射路径）
